# winvm commands

Generated by `bun scripts/skills.ts` from winvm's own usage text (`winvm help`).
Don't edit it by hand. Every command takes `-i NAME`; see the winvm skill.

```text
winvm <command>

  setup                         install missing host prerequisites, fetch pinned media
  doctor  [--json]              check host prerequisites (the HOST, before anything runs)
  diagnose [-i name]            explain a guest that misbehaved, from its files
  build --iso <win11.iso>       build a base image (once, ~20 min)
        [--payload <dir>] [--bun <version>] [--image <name>]
  adopt <disk.qcow2>            adopt an installed disk as a base image
  ls                            images and instances, with disk usage (--json: names only)
  create  [-i name] [--image NAME]   a new instance from an image, not started
  start   [-i name] [--ephemeral] [--no-autosave] [--boot] [--no-watch]
                                recalls a stow save if present (--boot: discard it, boot cold)
                                --no-autosave: no baseline save on the first boot (idle
                                autosaves are `config autosave.enabled=false`)
                                --no-watch: no idle watcher (no autosave, stow or clock sync)
  exec    [-i name] [--qga] [--timeout S] -- <cmd>  run a command in the guest (via the agent when installed);
                                exits with its code, or 124 when --timeout (default 900) kills it
  agent   [-i name] install | status [--json]   the in-guest agent (fast exec, files, GUI)
          [-i name] connect [--json]   update it if need be, then print its address and token
  put     [-i name] <host path> <guest path>    copy a file, or a folder and all in it, into the guest
  get     [-i name] <guest path> <host path>    copy a file, or a folder and all in it, out of the guest
  dir     [-i name] [path] [--all] [--places] [--json]   a guest folder (default the Desktop);
                                --all: hidden files too; --places: the known folders
  mkdir   [-i name] <guest path> [--json]       a new folder in the guest
  mv      [-i name] <from> <to> [--json]        rename, or move into the folder <to>; replaces nothing
  cp      [-i name] <from> <to> [--json]        copy in the guest, a file or a whole folder; replaces nothing
  rm      [-i name] <guest path>... [--permanently] [--json]   to the Recycle Bin (--permanently: for good)
  launch  [-i name] -- <program> [args]         start it on the guest's desktop, detached
  script  [-i name] [--timeout S] <file.ps1|.cmd|.bat> [-- args]   copy it to C:\winvm\scripts and run it
                                (.ps1: Windows PowerShell 5.1); its output and exit code, as exec
  terminal [-i name] [--shell pwsh|powershell|cmd] [--cwd PATH]   a guest shell, in this terminal
          [--connect --json]    print the WebSocket URL and subprotocols for another client
          --shells [--json]     which shells the guest has (PowerShell 7 may be missing)
  smoke   [-i name] [--expect <v> | --expect-file <path>] [--probe <exe>]
  snapshot [-i name] [tag]      capture the running guest, RAM and all
           [--delete]           remove that snapshot instead
  rewind  [-i name] [tag] [--no-watch]  put the guest back: snapshot <tag> (default fresh),
                                else the save of that name (default: the automatic baseline)
  save    [-i name] [name] [--fast] [--note TEXT]  save the running guest to files (default name: a timestamp)
  load    [-i name] [name] [--no-watch]  load a save, running or stopped (default: the newest)
                                into a stopped instance it starts the watcher, like start
  saves   [-i name] [rm <name>] [--json]  list saves (kind, size, compatible) or delete one
  golden  create|reset [-i name] [--name golden]  settled mapped-ram save; reset to it in ~1 s
  pause | resume [-i name]      freeze / unfreeze the guest (resume fixes its clock)
  stow    [-i name]             save and shut QEMU down; the next start recalls it
  clock   [-i name] [--check]   guest-vs-host clock offset, and fix it
  status  [-i name] [--json]    what it's doing; with no -i and several instances, a table
  open    [-i name] [--web]     show the screen in Screen Sharing, or (--web) the browser;
          [--json]              or print the VNC ports and password for a client
          [--print]             print the URL instead of opening it
  web     [--port n] [--stop]   the browser view's local server, in the foreground
  screenshot [-i name] [file.png]  save the screen (default: <instance>/screenshots/)
  type    [-i name] "text"      type into the guest (US layout)
  key     [-i name] <combo>...  e.g. ctrl-alt-delete, win-r, enter, f5
  click   [-i name] <x> <y> [--right|--middle] [--double]   screenshot pixels
          [-i name] --text TEXT [--wait S]   OCR the screen, click the middle of TEXT
  ocr     [-i name] [--find TEXT] [--wait S] [--fast] [--json] [--image f.png]
                                the screen's text and boxes (macOS Vision)
  toasts  [-i name] [--since T] [--app A] [--find TEXT] [--wait S] [--json]
                                notifications apps raised (T: ISO time, or 90s/5m/2h ago)
  move    [-i name] <x> <y>     move the pointer
  scroll  [-i name] <n>         n wheel notches, positive is down (or: up|down [n])
  display [-i name] [WxH] [--scale PCT]   resize the running screen live (virtio-gpu)
          [-i name] virtio-gpu|ramfb       switch a stopped instance's display device
  webview [-i name] enable <exe> | targets | eval <js> | click|wait|text <selector>
                                drive WebView2 windows over DevTools (winvm webview for more)
  ui      [-i name] <verb> [selector]   find and click windows, controls, the tray (winvm ui help)
  cua serve [-i name] [--port N] [--size WxH]   Claude computer-use endpoint on 127.0.0.1 (bearer token)
  cua run [-i name] "<task>" [--model M] [--max-steps N] [--extras]   a computer-use agent loop
  mcp     [-i name]             the guest as an MCP server on stdio, for Claude Code and Claude Desktop
  mcp install|uninstall claude-code|claude-desktop [-i name] [--json]   add it to Claude, or take it out
  mcp status [-i name] [--json] whether Claude Code and Claude Desktop have it
  timemachine [--yes]           exclude the VM files from Time Machine backups
  skills  [status] [--json]     winvm's agent skills: where Claude Code, Codex and Copilot see them
  skills  install|uninstall [--claude-code] [--codex] [--copilot] [--agents] [--all] [--json]
                                link them into ~/.claude/skills and ~/.agents/skills (no flag: --all)
  skills  pack [--out DIR] [--json]   one zip per skill, to upload to Claude Desktop
  skills  path                  print the folder they are in
  snapshots [-i name]           list them
  reset   [-i name]             discard changes, back to the base image
  rmi <image> [--force]         remove a base image (undoes its read-only seal)
  prune [--media]               drop leftover build scratch instances, and cached media
  stop | kill [-i name]
  destroy [-i name] [--keep-saves]  remove the instance and its saves
  watch   [-i name]             run the idle watcher in the foreground (start runs it in the background)
          [--stop | --status]   end it / print its state
  config  [-i name] [key=value ...]  autosave/stow/watch settings and the app's title; bare prints them
  run     <job.yml>... [-i name] [--golden NAME] [--keep] [--junit f] [--json f] [--artifacts dir]
                                run CI jobs, each from a golden save (instance default "ci")
          [--pool N] [--pool-prefix ci]   on N instances at once (ci-1 … ci-N)
  test    <dir>... [same flags] every *.yml in the directory, in order

  state:    WINVM_HOME       (default ~/.local/state/winvm)
  iso:      WINVM_ISO        (else asked once, then remembered)
  instance: WINVM_INSTANCE / -i   (default "default")
  image:    WINVM_IMAGE / --image (default "win11-arm64")
```
